# Assets / Images

Drop images here to make your profile more visual. Suggested additions:

- `headshot.jpg` — a professional photo for your README header
- `timeline.png` — a designed version of your experience timeline
- `skills-matrix.png` — a visual of your skills ratings
- Project screenshots — e.g., your Power BI dashboard (CIS 409) or Python charts (CIS 404)
- Certificates — Excel, Google PM, etc.

To show an image in any markdown file:

```markdown
![description](assets/images/your-image.png)
```

> Tip: keep file names lowercase with no spaces, and compress large images so the repo stays light.
